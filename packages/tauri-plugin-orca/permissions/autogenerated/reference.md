## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-runtime-platform`
- `allow-configure`
- `allow-identify`
- `allow-logout`
- `allow-query-products`
- `allow-purchase`
- `allow-get-active-entitlements`
- `allow-active-product`
- `allow-list-entitlements`
